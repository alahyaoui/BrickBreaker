# BrickBreaker

A browser-based clone of the classic Brick Breaker game built with JavaScript, jQuery, HTML and CSS. Smash bricks, keep the ball in play, and compete for the high score!

---

## Demo

Try it live: [retro-brick-breaker.herokuapp.com](https://retro-brick-breaker.herokuapp.com/)

---

## Features

- Smooth paddle control via mouse or touch  
- Accurate collision detection and ball physics  
- Multiple levels with progressively harder brick layouts  
- Score tracking and high-score display  
- Zero-backend: fully static, deploy anywhere  

---

## Installation

1. **Clone the repo**  
   ```bash
   git clone https://github.com/alahyaoui/BrickBreaker.git
   cd BrickBreaker
   ```
2. **Serve the files**  
   - **Option 1**: Open `index.html` directly in your browser  
   - **Option 2**: Deploy to any static hosting (GitHub Pages, Netlify, Heroku, etc.)

---

## Usage

- Move your mouse (or swipe) to control the paddle  
- Prevent the ball from falling off the bottom edge  
- Break all bricks to advance to the next level  
- Press **R** to restart the current level
